# GBA statistics display

Approved design: two purple landscape GBA consoles, D-pad and A/B buttons, green LCD screens with Chinese labels and pixel numbers.

Implementation: generate standalone SVGs with Python standard library; read GitHub release download counts and the existing Hits read-only statistics endpoint. Keep the original Hits badge as a one-pixel counting image so visits continue using the same key. GitHub Actions refreshes hourly and on manual dispatch, committing only changed image/data files. No new hosting service or credentials. Counts retain existing semantics; deleted assets are excluded. On API failure leave existing displays untouched and fail the job.

Validation: generate from live APIs, validate SVG XML and numeric totals, inspect a rendered preview, publish README and workflow, run workflow and confirm completion.
