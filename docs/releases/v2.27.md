# CARTIS 2.27 · 全平台合集与响应优化

以2.26为基础合并2.25配色修复，保留原包名与签名，支持覆盖升级。正式安装包：`CARTIS-2.27.apk`（versionCode27），KPB已实机验证；KPA及其他设备未完成本整包回归。

## 新功能与界面

- 全平台搜索，选择结果后定位到对应平台和卡带，不直接运行。
- Select默认本平台合集，L/R切换全平台合集；同一全平台合集可收纳不同平台的游戏。
- X详情中提供全平台合集、本平台合集两个独立按钮。
- 设置→性能支持向上滑动启动，默认向下滑动。
- 合集与游戏平台页统一使用游戏选择页的原生顶部栏，L/R可实体键或触摸切换，机型名称移到顶部，数量区域保留并放大字体。
- 深色模式底栏匹配游戏名称按钮的玻璃颜色；关闭、支持等红绿功能按钮保持原色。
- 修复重复底栏排版、无效的平台缓存清理和全平台游戏路径的低效查重；玻璃绘制跟随KPB现有质量设置。

## 按键响应实测

同一KPB、同配置、深色模式、GBA504游戏：2.23与最终2.27各96次转换全部成功。每条入口首次1轮、重复5轮，下表为重复首帧中位数：

| 操作 | 2.23 | 2.27 | 等待降低 |
| --- | ---: | ---: | ---: |
| Select进入合集 | 707.1ms | 337.5ms | 52.3% |
| X打开详情 | 310.9ms | 108.9ms | 65.0% |
| Start搜索 | 362.2ms | 199.9ms | 44.8% |
| Y设置 | 398.6ms | 223.3ms | 44.0% |
| X第二层详情 | 362.3ms | 179.8ms | 50.4% |

其余11条路径差异均小于一帧，不能据此认定稳定变化。测量是映射输入事件到目标引擎首帧，不含手柄/USB物理轮询与面板扫描，不是模拟器启动速度；未固定CPU频率，样本不足以稳定估计P95。首次样本、完整16条路径及原始数据见本发布附件。
