# CARTIS 2.0 · 像素加载页、新图标与完整关于页

本次版本沿用原包名与签名，支持覆盖安装。请备份配置与存档，不要卸载或清除数据。

## 本次更新

- CARTIS 名称与新的像素鸟图标：裁剪外围留白，适配 Android 桌面与应用信息页。
- 新像素加载画面：根据屏幕比例完整显示，真实阶段进度填充预留进度框，CARTIS和阶段文字保留在下方。
- 关于页更紧凑，一页显示全部介绍；图标左上、蓝色感谢按钮右上，感谢可进入支持页；移除图标预览按钮。
- 补充来源：基于Socket 0.6，原作者depmots；感谢HI问风（bilibili）提供资源与汉化。保留Creepynuts、小红书同名、版本2.0和BBM-UPGRADED!。

## 相较原版已完成的功能

新增平台选择页及GBC等模型、GBA SP/NDS/3DS开盖互动、点击放大模型360°观赏、特定机型开机音与背景音、两档模型质量、页面过渡动画、合集与搜索、覆盖升级与KPA适配。用户反馈的问题持续维护修复。

## 本版本累计保留

- 平台独立合集及排序，游戏添加合集选项随平台和顺序同步。
- KPB/KPA屏幕布局调整、NDS模型缩小修正。
- 点阵背景批量绘制、游戏库缓存生命周期优化；透明外壳、封面、八模型后台缓存保留。
- 性能、按键和支持设置及配置持久化。

## 验证与边界

最终包在KPB覆盖安装，并核对设备APK哈希；实机检查启动完成、关于页一页显示与感谢跳转。加载/图标修改阶段也做了熄屏亮屏恢复检查。关于页960×720/960×640目标尺寸布局检查通过，最终整包未在KPA实机重新验证，2GB KPB未验证。

稳定检查点测得GBA静止41.19 FPS、左右切换39.34 FPS（30秒），切换P95帧间隔49.58ms，最大66.15ms，超过100ms为0。最终视觉更新保持模型/材质/质量策略字节一致，但未对最终视觉包另做完整帧率复测；这些数据不是稳定60 FPS或所有设备承诺。

本轮后续性能实验已暂停，没有集成取消透明折射、改不透明外壳、继续降低分辨率或OpenGL实验。游戏运行仍需要另装模拟器和对应核心；安装包不包含游戏或BIOS。
