# CARTIS 2.0 · 平台卡带缩放修复（KPB 实测）

修复在“设置 → 平台”将3D模型缩放调至0.9、0.8后，卡带变灰、封面近乎消失的问题。各卡带平台共用相机逻辑，本次一并修正。

- 原因：缩小时相机后移，但距离雾的范围固定，导致卡带被灰雾覆盖。
- 修复：雾化范围跟随相机后移；使用相机独立的环境副本，不影响其他视图。保留模型、材质、透明外壳与封面。
- GBA 0.9、0.8已在KPB实机验证；NDS、PSP、PSX、GBC、GB在0.8下模型正常。3DS、PS2使用临时条目检查模型渲染，未验证真实游戏启动。
- 回归覆盖0.5～2.0、越界钳制、反复切换及多相机环境隔离。
