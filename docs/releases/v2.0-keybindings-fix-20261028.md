# CARTIS 2.0 · 按键改绑修复与平台快捷切换

基于 v2.0-core-rollback-20261028，versionCode 19 → 20。同签名覆盖安装，保留原有配置；请勿先卸载或清除数据。

- 修复游戏平台改绑为 Select＋Start 后，旧 L＋R 仍能打开平台选择页的问题。
- 新增“上一个游戏平台”：默认 **十字键左＋R1**，直接进入上一个可见平台的完整游戏列表。
- 新增“下一个游戏平台”：默认 **十字键右＋R1**，直接进入下一个可见平台的完整游戏列表。
- 两项均可在 **设置 → 按键** 改绑；按可见游戏平台顺序首尾循环。
- 十字键单独使用仍正常导航，L / R 单键继续切换合集。支持按住 R1 连续点按方向，不会在松开 R1 时额外切换合集。
- 原有 Select＋Start 等自定义绑定保持；模拟器内按键与存档不作修改。

测试：235 项引擎自动检查，以及 KPB 上 23 项应用流程与安卓键盘事件验证通过。覆盖全部 12 个可配置功能、组合按下顺序、旧键失效、单/双/三键改绑、作用域、冲突替换、保存重载、恢复默认、平台循环和录入界面。手柄流程通过实际应用中的 Godot 输入事件自动注入；没有宣称人工逐键硬件测试。KPA 及其他设备尚未实测。
