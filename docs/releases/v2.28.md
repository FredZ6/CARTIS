# CARTIS 2.28 · 中文路径封面匹配与缓存修复

基于正式2.27维护，沿用原包名与签名，可覆盖安装。安装包 **CARTIS-2.28.apk**（versionCode 28）。本发布为封面修复版，保留2.27的全平台搜索、跨平台合集、菜单配色与按键响应优化。

## 修复内容

- 修复通过安卓系统文件选择器添加中文目录后，游戏数量正确但本地封面无法匹配的问题。
- 自动封面缓存增加来源路径与修改时间指纹，避免同名游戏复用旧游戏包或测试图片；保留手动指定封面。
- 已有游戏自动重新匹配本地 `lmgs` 图片，无需删除平台或重新下载游戏。

## 安装与首次匹配

直接覆盖安装，不要卸载或清除数据。首次打开等待后台匹配完成，再关闭并重新打开 CARTIS，使当前卡带加载已修复的封面。首次处理大量图片可能需要一段时间。

## English

CARTIS 2.28 fixes local cover matching for Chinese-named folders selected through Android's system folder picker, plus stale automatic cover-cache reuse. It retains the official 2.27 features and signing certificate.

Install over the existing app without uninstalling or clearing data. Let the first background matching pass finish, then close and reopen CARTIS. There is no need to delete platforms or download the games again.

On KPB, all 809 local covers (536 NES, 108 GB, 165 GBC) matched their source pixels; the original 504 GBA covers were preserved. All 222 regression assertions passed. Other devices and online scraping services are outside this verification scope.

**The Baidu mirror may lag behind; use GitHub Releases for the latest version.** The retained mirror is for 2.27 and is not a confirmed 2.28 mirror.
