# Socket BBM 2026-10-25：平台独立合集与排序测试报告

## 功能

每个平台的游戏页按 Select 打开本平台合集列表。十字键选择，A 进入，Y 新建，X 编辑，B 返回。X 编辑支持改名、逐个移除成员和删除确认；删除只影响合集，不删除游戏文件或存档。设置中的旧合集入口已移除。

Select 页选中自建合集后，L/R 前移或后移；游戏页的合集分类与游戏 X 查看 → 合集列表同步使用同一顺序。收藏、最近游玩及完整游戏库固定在前面。不同平台可以创建同名合集，编辑、删除及游戏加入／移出不会串到其他平台。平台实例按机种与游戏目录分别归属。

改名保留原位置；空合集可显示、进入和编辑。写入失败会报告失败并撤回内存修改。弹出软键盘时，名称与确认区保持可见；手柄确认键松开后再唤起键盘，减少输入法误收按键。

## 数据迁移与保护

更新前备份了原 APK、完整 Socket 数据和关键配置。旧合集按成员所属平台迁移，原 17 个合集、408 条成员关系均保留；本设备的旧合集均属于 GBA，其他平台从空列表开始。旧 collections 段留作迁移归档，版本标记防止已删除合集再次迁移回来。

测试结束已删除临时合集。冷启动确认迁移结果持久化。原游戏库、质量、互动、按键、搜索、同步及 RA 配置核对一致。个人备份和配置未包含在公开附件中。
