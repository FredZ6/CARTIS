# KPB 性能实测

[项目 README](../../README.md) · [English](README.en.md)

以下为 KPB 历史版本的实测数据。每项报告列出了测试场景、设备配置和测量口径。

## 性能改进：以测试记录为准

本轮测试说明见 [KPB 性能对照报告](../reports/2026-10-27-kpb-performance.md)。

| 测试场景 / 指标 | 优化前 | 优化后 | 测试范围 |
| --- | --- | --- | --- |
| KPB 主机模型放大、持续旋转 | 45.66–46.28 FPS | 57.40–57.50 FPS | 相同动作交替 A/B 复测，点阵背景批量绘制 |
| KPB GBA 卡带左右切换 | 36.45–36.61 FPS | 39.07–39.30 FPS | 同一真实输入分发动作的 A/B 测试 |
| 上述 GBA 切换 P95 帧间隔 | 约 82.64 ms | 约 49.56 ms | 长帧间隔缩短；不是平均帧时间 |
| KPB 主机模型放大场景绘制调用 | 约 1,562 次 | 约 111 次 | 批量绘制背景后，单帧 draw calls 减少 |
| 较早启动优化的三轮平均冷启动 | 17.40 秒 | 17.03 秒 | 2026-10-25 同口径报告，提升约 2.1% |
| 上述测试中八模型缓存准备时间 | 21.13 秒 | 20.24 秒 | 较早构建，提升约 4.2%，不代表首屏等待时间 |

稳定无诊断包另测得 GBA 静止 **41.19 FPS**、左右切换 **39.34 FPS**；30 秒切换采样中超过 100 ms 的帧为 0。不同页面和操作必须分开比较，不能把主机模型接近 60 FPS 写成所有场景稳定 60 FPS。

**内存、耗电和热启动**：八模型缓存继续保留；本轮没有完整的同口径内存、耗电与热启动对照数据，因此不宣称降低百分比，也不使用“冷启动、热启动减少 50%”的说法。较早的后台缓存报告见 [内存与恢复测试](../reports/2026-10-25-background-model-cache.md)，启动数据见 [冷启动测试](../reports/2026-10-25-startup-optimization.md)。

## 与2.23的按键响应对比

同一KPB、同配置、深色、GBA504游戏，两版各16条路径×6轮，共192次转换全部成功。下表为**输入事件到目标页面首帧**的重复操作中位数，每条取后5轮；不是模拟器启动时间，也不是所有场景的帧率。

| 操作 | 2.23 | 2.27 | 等待降低 |
| --- | ---: | ---: | ---: |
| Select进入合集 | 707.1 ms | 337.5 ms | 52.3% |
| X打开详情 | 310.9 ms | 108.9 ms | 65.0% |
| Start打开搜索 | 362.2 ms | 199.9 ms | 44.8% |
| Y打开设置 | 398.6 ms | 223.3 ms | 44.0% |
| X第二层详情 | 362.3 ms | 179.8 ms | 50.4% |

其余11条路径的中位差值均小于60Hz下一帧（16.7ms），不据此认定稳定变化。首次样本、范围、测试顺序与限制见[完整16项数据报告](../reports/2026-10-29-key-latency.md)；可下载[PDF](https://github.com/FredZ6/CARTIS/releases/download/v2.27/CARTIS-2.23-vs-2.27-latency-report.pdf)与[原始数据包](https://github.com/FredZ6/CARTIS/releases/download/v2.27/CARTIS-2.23-vs-2.27-latency-data.zip)。

本轮另通过126项功能断言、36项深浅色底栏检查、8项模型/应用页检查、16项红绿按钮保色检查、60项主题与24项合集存储检查。较早的按键修复记录见[历史回归报告](../reports/2026-10-28-keybindings.md)，模型缩放说明见[平台缩放修复报告](../reports/2026-10-27-camera-zoom-fix.md)。
