## 安装说明

1. 在 [Releases 下载页面](https://github.com/FredZ6/kpb-socket/releases/latest) 下载 `.apk` 安装包，不要下载 Source code 压缩包。
2. 将 APK 复制到掌机，用文件管理器打开；按安卓提示允许该文件管理器安装应用，然后完成安装。
3. 首次使用时，授予游戏目录的读取权限，并根据下面的说明添加游戏平台。
4. 如需按 Home 从模拟器回到 Socket，请在安卓的默认应用设置中将 **socket-bbm** 设为默认桌面。不同设备的菜单位置可能不同。

已安装 socket-bbm 时，请直接覆盖更新，保留原应用数据。更新前建议备份配置，不要先卸载或清除数据。

安装包不包含游戏、BIOS、模拟器、封面素材或个人配置。请准备自己有权使用的游戏，并另外安装对应模拟器。RetroArch 需要安装相应核心；独立模拟器请先完成初始设置，确认游戏能在模拟器中运行，再配置 Socket 的启动方式。

中文搜索使用安卓系统输入法。若键盘能显示但无法输入，可先切换一次中英文语言；需要时更换支持中文的输入法。输入法不包含在本 APK 内。

### 自定义按键

进入 **设置 → 按键**，选择要修改的功能，按下希望绑定的实体键，全部松开后选择“保存绑定”。支持最多 3 个按键的组合，例如 L＋R。

- 可绑定确认、返回、设置、应用、查看、合集、搜索、上一个 / 下一个合集及游戏平台。
- 同一页面的重复绑定会提示冲突；选择替换会解除冲突功能的旧绑定。
- 保存后立即生效，重启后保留；底部提示跟随绑定更新。
- “恢复默认按键”可清除自定义绑定。
- 录入过程中 B 本身也能被绑定，取消录入请触屏点击“取消录入”，或使用安卓返回键。
- 方向键保留导航用途，Home 由安卓系统处理，不作为普通自定义键。Home 返回 Socket 依赖默认桌面设置。

这些设置只影响 Socket；RetroArch 和其他模拟器的按键、快进、存档快捷键需要在对应模拟器里配置。

## 游戏与封面导入

游戏资源和封面可以通过这个链接下载：[夸克网盘下载](https://pan.quark.cn/s/8deecaf6406f)。

### 1. 整理游戏目录

建议在掌机内部存储或 SD 卡中，按游戏平台分别建立文件夹。下面是内部存储示例，`天马游戏包` 不是强制名称，也可以自行命名：

```text
内部存储/
└── 天马游戏包/
    ├── GBA/
    │   ├── 口袋妖怪 水银.gba
    │   ├── 逆转裁判1.gba
    │   └── lmgs/
    │       ├── 口袋妖怪 水银.png
    │       └── 逆转裁判1.png
    ├── NDS/
    │   ├── 游戏名称.nds
    │   └── lmgs/
    │       └── 游戏名称.png
    ├── PSP/
    │   ├── 游戏名称.iso
    │   └── lmgs/
    │       └── 游戏名称.png
    └── PS1/
        ├── 游戏名称.chd
        └── lmgs/
            └── 游戏名称.png
```

上述 GBA 目录对应安卓路径 `/storage/emulated/0/天马游戏包/GBA`。SD 卡路径因设备而异，请在目录选择器中选择实际文件夹，不要照抄别人的 SD 卡编号。

示例扩展名仅用于说明目录结构。实际支持的游戏格式由平台扫描规则和所选模拟器共同决定。下载的游戏如带有多层压缩包，请先解压并整理；光盘游戏的配套文件应一起保留。

### 2. 准备封面

在**每个平台的游戏目录内**建立 `lmgs` 文件夹，把封面放进去。

**注意：`lmgs` 是小写字母 l 开头，不是 `imgs`，也不是数字 1。**

封面图片的文件名应与游戏文件去掉扩展名后的名字一致：

| 游戏文件 | 对应封面 |
| --- | --- |
| `口袋妖怪 水银.gba` | `lmgs/口袋妖怪 水银.png` |
| `游戏名称.nds` | `lmgs/游戏名称.png` |
| `游戏名称.iso` | `lmgs/游戏名称.png` |

支持 PNG、JPG、JPEG、WebP 和 BMP，建议使用 PNG 或 JPG。不要只修改图片扩展名来转换格式。为避免匹配错版本，尽量让图片与游戏文件的名称完全一致。

### 3. 在 Socket 中添加平台

1. 打开 **设置 → 平台 → 添加平台**。
2. 选择对应的游戏平台和已安装的模拟器，配置相应核心或启动方式。
3. 选择该平台的**游戏目录**，例如 `天马游戏包/GBA`，不要选择其中的 `lmgs` 目录。
4. 授予目录访问权限，保存并等待游戏扫描和封面匹配完成。
5. 回到主界面查看游戏；按 L＋R 可进入游戏平台选择页。

每个平台分别添加一次。文件夹名称本身不会代替平台设置，也不代表模拟器已安装。若未显示游戏，先核对选中的目录、文件格式和访问权限。

### 4. 后续添加游戏或更换封面

把新游戏及同名封面复制到对应平台目录后，在平台设置中重新扫描。也可以重新进入 Socket，等待自动匹配完成。

封面没有显示时，依次检查：

- 文件夹是否确实叫 `lmgs`，且放在该平台的游戏目录内。
- 图片名称是否与游戏原文件名一致，而不是只与界面中修改过的显示名称一致。
- 图片是否能正常打开，扩展名是否与真实格式相符。
- 游戏目录是否仍有读取权限，SD 卡是否已挂载。

替换已有封面后若仍显示旧图，先重启 Socket 再检查；也可进入该游戏的自定义界面手动选择封面。无需卸载应用或清除全部配置。
